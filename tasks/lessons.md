# Lessons

## width/height-атрибуты картинок требуют `img { height: auto }` в CSS
Добавление `width`/`height` атрибутов (для резервирования места против CLS) картинкам,
которые CSS ресайзит только по ширине (`width: 100%`), сплющивает их: атрибут height
действует как презентационный хинт и фиксирует высоту. Всегда сопровождать правилом
`img { height: auto }` в reset — тогда высота следует пропорции из атрибутов.
Проверять аудитом Lighthouse `image-aspect-ratio` после таких правок.

## Bun-бандлер (1.3.x) и ассеты
- `url()` в CSS всегда инлайнится в base64 (data URI), `--loader .woff2:file` не помогает —
  шрифты подключать через import ассета в JS + FontFace API (бандлер кладёт файл хэшированным).
- `srcset`/`<picture>` не поддерживаются — весь атрибут трактуется как один путь и падает резолв.
- Inline `<style>` в HTML бандлер не трогает вообще (url() не резолвится и файл не копируется).
- Dev-сервер `bun index.html` отдаёт HTML-фолбэк (SPA) на любой путь вне бандла — статические
  файлы «рядом с проектом» не сервируются; проверять `curl` не только код 200, но и Content-Type.
- `Bun.serve` с HTML-импортом требует react-refresh runtime в dev-режиме (даже без React).
